# 🚀 Taskly v1.0.0 — Official GitHub Release Notes

We are thrilled to announce the official v1.0.0 release of **Taskly** — a modern, high-performance task management application designed for desktop, mobile, and cloud environments!

## ✨ What's New in v1.0.0

- 🌓 **Dual Eye-Comfort Themes**: Toggle instantly between **Light Theme** (Warm Pastel Cream) and **Dark Theme** (Eye-Comfort Obsidian Charcoal `#121318`).
- 📅 **Interactive Calendar View**: View scheduled tasks with uniform 100% proportional day tiles and an infinite Month/Year picker modal.
- 📱 **Android PWA & Native Capacitor APK**: Install natively on Android phones via PWA or build an Android `.apk` package using Capacitor.
- ⚡ **Dual Engine Architecture**: Works seamlessly connected to the Python Flask REST API or 100% offline via `localStorage`.
- 📦 **Data Exporting**: Download timestamped JSON and CSV backups from CLI or API.
- ☁️ **Vercel Cloud Ready**: 1-click cloud deployment via `vercel.json`.

## 📦 Downloads & Installation

- `Taskly-v1.0.0-WebBundle.zip`: Source code and web package ready for standalone server or web hosting.
- **Run locally**: `./start.sh`
- **Deploy to Vercel**: `vercel`
